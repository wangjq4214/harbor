Design Decisions

  • Screen-Buffered Outbox: Storing the outgoing bytes in a flat vector inside Screen avoids introducing channels, threads, or callbacks at the parser boundary.
  • Immediate PTY Writeback: Draining and writing replies immediately after terminal.process_output(&bytes) ensures that interactive applications do not timeout.
  • Coordinate Decoupling: CPR coordinate calculation checks self.modes.origin and self.margins.enabled independently to match DEC standards.
  • 1024-byte Buffer Cap: Prevents malicious sequences from causing memory bloat by enforcing a strict length ceiling on pending replies.

3 Implementation Steps

Step 1: Add replies buffer to Screen

crates/harbor-terminal/src/screen.rs

Add pub(crate) replies: Vec<u8> to the Screen struct. Initialize it in Screen::new. Implement push_reply(&mut self, reply: &[u8]) and drain_replies(&mut self) -> Vec<u8>.

pub fn push_reply(&mut self, reply: &[u8]) {
    if self.replies.len() + reply.len() <= 1024 {
        self.replies.extend_from_slice(reply);
    } else {
        tracing::warn!("Reply buffer limit reached. Discarding reply.");
    }
}
pub fn drain_replies(&mut self) -> Vec<u8> {
    std::mem::take(&mut self.replies)
}
Screen owns a thread-safe, bounded, platform-neutral outbox vector.

Step 2: Add CSI 'n' handling to ScreenHandler

crates/harbor-terminal/src/parser/handlers.rs

Add a match arm for b'n' in csi_dispatch to handle standard and private Device Status Reports (DSR) and Cursor Position Reports (CPR).

b'n' => {
    let mode = params.get_or(0, 0);
    if let Some(b'?') = private_marker {
        if mode == 6 {
            // Private CPR
            let row = if self.screen.modes.origin {
                (self.screen.cursor.y.saturating_sub(self.screen.scroll_region.top)) + 1
            } else {
                self.screen.cursor.y + 1
            };
            let col = if self.screen.modes.origin && self.screen.margins.enabled {
                (self.screen.cursor.x.saturating_sub(self.screen.margins.left)) + 1
            } else {
                self.screen.cursor.x + 1
            };
            let reply = format!("\x1b[?{};{}R", row, col);
            self.screen.push_reply(reply.as_bytes());
        }
    } else {
        match mode {
            5 => {
                // Device Status Report
                self.screen.push_reply(b"\x1b[0n");
            }
            6 => {
                // Standard CPR
                let row = if self.screen.modes.origin {
                    (self.screen.cursor.y.saturating_sub(self.screen.scroll_region.top)) + 1
                } else {
                    self.screen.cursor.y + 1
                };
                let col = if self.screen.modes.origin && self.screen.margins.enabled {
                    (self.screen.cursor.x.saturating_sub(self.screen.margins.left)) + 1
                } else {
                    self.screen.cursor.x + 1
                };
                let reply = format!("\x1b[{};{}R", row, col);
                self.screen.push_reply(reply.as_bytes());
            }
            _ => {}
        }
    }
}
DSR status query, standard CPR, and private CPR are processed and written to the Screen's buffer.

Step 4: Wire up writeback in terminal_worker

src/terminal_worker.rs

Modify the apply_command logic for PtyOutputBytes to immediately drain and write back replies to the PTY.

TerminalCommand::PtyOutputBytes(bytes) => {
    set_status(mailbox, WorkerStatus::Processing);
    terminal.process_output(&bytes);
    let replies = terminal.drain_replies();
    if !replies.is_empty() {
        pty.write(&replies);
    }
    *revision = revision.saturating_add(1);
    publish_snapshot(terminal, mailbox, notifier, *revision, true, None);
    set_status(mailbox, WorkerStatus::Idle);
}
Outgoing bytes are transmitted back to the PTY immediately after processing input data.

5 Test Strategy

TerminalParser & Screen Tests

Target
Verify parser-to-reply correctness under varying DECOM/DECSLRM configurations.
Cases
  • CSI 5 n: Assert reply contains exactly \x1b[0n.
  • CSI 6 n (Absolute): Place cursor at absolute row 3, col 4. Assert reply is \x1b[4;5R.
  • CSI 6 n (DECOM active, LR Margins active): Configure margins, place cursor, assert relative offsets.
  • CSI 6 n (DECOM active, LR Margins inactive): Assert relative row, absolute column.
  • CSI ? 6 n: Assert reply format \x1b[?row;colR.
  • 1024-byte overflow: Push multiple 6n queries in one batch, assert total replies byte count is capped at 1024 bytes.
