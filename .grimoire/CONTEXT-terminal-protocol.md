# Terminal Protocol Domain

Protocol concepts belonging to Terminal. Linked ADRs define detailed validation/security policy; support and runtime acceptance require separate evidence.

### harbor-parser
- **Definition:** Zero-dependency streaming VT/ANSI state machine consumed by harbor-terminal. Its public boundary is Parser, Params and VtHandler; accumulators and UTF-8 decoder remain private.
- **Synonyms:** VT Parser

### VtHandler
- **Definition:** Statically dispatched callback trait translating parsed print/control/CSI/ESC/OSC/DCS/string actions into terminal handling, with Params and CSI Private Marker preserving wire distinctions.

### CSI Private Marker
- **Definition:** An optional raw byte passed through `VtHandler::csi_dispatch` to preserve the distinct `?`, `>`, `<`, and `=` CSI prefixes without adding another public parser type.
- **Relationships:**
  - belongs to harbor-parser

### Params
- **Definition:** An opaque container for CSI/DCS numeric parameters, supporting flat iteration and colon-separated sub-parameters. Internal representation is hidden.

### TerminalReply
- **Definition:** A platform-neutral 1024-byte buffer in the Screen struct that atomically accepts or drops complete outgoing terminal protocol replies generated by the VT parser.
- **Synonyms:** ReplySink, Screen-buffered replies
- **Relationships:**
  - communicates with Primary DA
  - communicates with Secondary DA
  - communicates with DSR
  - communicates with CPR
  - communicates with DECRQSS
  - communicates with XTGETTCAP

### DECRQSS
- **Definition:** A VT status-query protocol that Harbor accepts as 7-bit `DCS $ q Pt ST` and answers through TerminalReply for SGR, DECSTBM, DECSLRM, DECSCUSR, and DECSCA state.
- **Synonyms:** Request Status String

### XTGETTCAP
- **Definition:** A VT terminfo-capability query where an application sends `DCS + q Pt ST` with `Pt` as semicolon-separated hex-encoded capability names, and Harbor replies `DCS 1 + r Pt ST` listing hex-encoded `name=value` entries (or name-only booleans) for its registry-backed capabilities (`TN` = `xterm-256color`, `RGB` = `8/8/8`, `Co`/`colors` = numeric 256, `U8` = numeric 1 preferring Unicode line drawing in UTF-8 locales, legacy `u8` = name-only UTF-8 boolean, `Su` = styled-underline boolean) or `DCS 0 + r ST` when none match.
- **Synonyms:** Terminal Capability Query, tcap query
- **Relationships:**
  - depends on TerminalReply

### Terminfo Capability Declaration
- **Definition:** Harbor's private compile-time XTGETTCAP name/value registry, not a terminfo database installed on the host or remote system. Capability names are case-sensitive. Harbor's legacy lowercase `u8` name-only boolean is distinct from ncurses' extended numeric `U8`, which controls Unicode versus ACS line drawing in UTF-8 locales, not general UTF-8 support; see [ncurses user_caps(5)](https://invisible-island.net/ncurses/man/user_caps.5.html). The currently supported values are defined under XTGETTCAP.

### CPR
- **Definition:** A VT control sequence reply containing the current line and column coordinates of the terminal cursor.
- **Synonyms:** Cursor Position Report
- **Relationships:**
  - depends on TerminalReply

### DSR
- **Definition:** A VT query and corresponding reply sequence used to report the operating status of the terminal.
- **Synonyms:** Device Status Report
- **Relationships:**
  - depends on TerminalReply

### Capability Registry
- **Definition:** Private compile-time source of deterministic Primary DA and Secondary DA replies; the identities are defined under those entries.
- **Relationships:**
  - references TerminalReply

### Primary DA
- **Definition:** The exact VT Device Attributes reply `ESC [ ? 62 ; 6 ; 17 ; 22 ; 28 c` sent for an omitted or zero DA parameter to identify Harbor conservatively as VT220/Level 2 with only evidence-backed capabilities.
- **Synonyms:** Primary Device Attributes
- **Relationships:**
  - depends on Capability Registry
  - depends on TerminalReply
  - extends DECID

### Secondary DA
- **Definition:** The stable VT Device Attributes identity reply `ESC [ > 1 ; 1 ; 0 c`, identifying VT220 compatibility, Harbor DA protocol revision 1, and no DEC hardware option.
- **Synonyms:** Secondary Device Attributes
- **Relationships:**
  - depends on Capability Registry
  - depends on TerminalReply

### Tertiary DA
- **Definition:** The unsupported VT Device Attributes query `CSI = c`, which Harbor safely ignores without producing a reply or side effect.
- **Synonyms:** Tertiary Device Attributes
- **Relationships:**
  - references TerminalReply

### DECID
- **Definition:** The legacy 7-bit identify query `ESC Z` that uses the same response builder and exact response bytes as Primary DA.
- **Synonyms:** DEC Identify
- **Relationships:**
  - depends on TerminalReply

### DA Query Compatibility
- **Definition:** Harbor responds only to 7-bit DA requests whose parameter is omitted or zero, ignores invalid parameter forms, and does not recognize 8-bit C1 DA forms in this feature scope.
- **Relationships:**
  - references Primary DA
  - references Secondary DA
  - references Tertiary DA
  - references DECID

### DECRQM
- **Definition:** A VT request for the state of one standard or DEC private terminal mode, encoded as `CSI Ps $ p` or `CSI ? Ps $ p`.
- **Synonyms:** DEC Request Mode
- **Relationships:**
  - depends on TerminalReply
  - communicates with DECRPM

### DECRPM
- **Definition:** A VT response reporting a queried standard or DEC private mode as set, reset, permanently set, permanently reset, or unknown.
- **Synonyms:** DEC Report Mode
- **Relationships:**
  - implements TerminalReply

### Streaming Parser Safety
- **Definition:** The bounded, cancellable, recoverable incremental-parser contract for arbitrary bytes; Arbitrary-Input Safety Evidence establishes rather than assumes it.
- **Synonyms:** Bounded parser contract, P1 parser safety
- **Relationships:**
  - belongs to harbor-parser
  - depends on Parser Retention Limits

### Parser Retention Limits
- **Definition:** Fixed caps in harbor-parser (`MAX_PARAMS` 16, `MAX_SUBPARAMS` 8, `MAX_INTERMEDIATES` 2, `MAX_CSI_PARAM` 65535, `MAX_OSC_BYTES` 4096, `MAX_STRING_BYTES` 4096) that bound retained CSI and string-family state.
- **Synonyms:** Fixed parameter/string limits

### Arbitrary-Input Safety Evidence
- **Definition:** Fuzz or property-test proof that arbitrary bytes do not panic, infinite-loop, or grow retained parser memory beyond Parser Retention Limits.
- **Synonyms:** Fuzz/property evidence
- **Relationships:**
  - implements Streaming Parser Safety

### String Overflow Discard
- **Definition:** After a string-family payload hits its byte cap, the parser stops retaining or delivering bytes and keeps scanning for ST or CAN/SUB cancellation.
- **Relationships:**
  - belongs to harbor-parser
  - depends on Parser Retention Limits

### DECALN
- **Definition:** The terminal alignment escape sequence `ESC # 8` fills every visible cell of the active buffer with default-styled `E`, clears wrap state, and homes the cursor without resetting modes, pen attributes, or character-set state.
- **Synonyms:** DEC screen alignment test
- **Relationships:**
  - depends on ESC Intermediate+Final Dispatch

### ESC Intermediate+Final Dispatch
- **Definition:** The parser route for ESC sequences containing intermediate bytes, which consumes unrecognized combinations without visible side effects and returns to Ground state.
- **Relationships:**
  - belongs to harbor-parser
  - communicates with VtHandler

### CHT (Cursor Forward Tabulation)
- **Definition:** The `CSI Ps I` terminal command that clears pending-wrap and moves the cursor forward by `Ps` tab stops, treating an omitted or zero parameter as one and clamping to the active right boundary when no further stop exists.
- **Synonyms:** Forward Tab

### CBT (Cursor Backward Tabulation)
- **Definition:** The `CSI Ps Z` terminal command that clears pending-wrap and moves the cursor backward by `Ps` tab stops, treating an omitted or zero parameter as one and clamping to the active left boundary when no further stop exists.
- **Synonyms:** Back Tab

### Alternate-Screen Mode Family
- **Definition:** The DEC private modes `?47`, `?1047`, `?1048`, and `?1049` that together provide an isolated alternate screen buffer and cursor save/restore: `?47` switches buffers without clearing, `?1047` switches and clears the alternate buffer on entry, `?1048` saves or restores the cursor only, and `?1049` combines cursor save with a clearing buffer switch.
- **Synonyms:** Alt-screen modes, DECSET/DECRST alternate screen
- **Relationships:**
  - contains Alternate-Screen Buffer Isolation

### Alternate-Screen Buffer Isolation
- **Definition:** Harbor's whole-screen swap technique that saves the entire primary `Screen` (cells, cursor, pen, modes, scrollback) and installs a fresh or persistent alternate `Screen`, so alternate-screen edits cannot corrupt primary scrollback and cursor save/restore is a superset of DECSC.
- **Relationships:**
  - depends on Alternate-Screen Mode Family

### Cursor Save/Restore (DECSC/DECRC)
- **Definition:** The terminal state snapshot mechanism that records cursor position and mode flags on DECSC/`CSI s`/`?1048 h` and restores them on DECRC/`CSI u`/`?1048 l`, with pen attributes saved separately by the pen state.
- **Synonyms:** Cursor save, SCP/RCP

### OSC 7 Working-Directory Metadata
- **Definition:** Per-tab optional structured `file://[host]/absolute-path` metadata, not filesystem authority or UI. Preserve URI path form, never normalize to a platform path or perform chdir, file reads or network access. Empty/RIS clears it; invalid input preserves prior state. Bounded host/path validation: [ADR 0033](./adr/0033-osc7-metadata-without-filesystem-side-effects.md).
- **Synonyms:** Current working directory metadata, CWD metadata
- **Relationships:**
  - communicates with Application Business Host
  - depends on Parser Retention Limits

### OSC 8 Hyperlink
- **Definition:** Terminal attribute opened by `OSC 8 ; params ; URI ST`, closed by empty URI. Cells carry compact IDs resolved by a bounded, reachability-cleaned screen registry ([ADR 0035](./adr/0035-cell-linked-bounded-registry-for-osc8-hyperlinks.md)); invalid/over-limit opens are rejected, not truncated. Primary-button clicks request host activation without Ctrl, only for http/https/mailto/file. Parsing/rendering never fetch targets ([ADR 0034](./adr/0034-direct-click-host-activation-for-osc8-hyperlinks.md)).
- **Synonyms:** Terminal hyperlink
- **Relationships:**
  - depends on Parser Retention Limits
  - communicates with Runtime Host

### OSC Default Color Policy
- **Definition:** OSC 10/11/12 set/query default foreground/background/cursor RGB; sets preserve Harbor alpha and queries mirror BEL/ST. OSC 110/111/112 explicitly reset RGBA. Bounded RGB syntax and invalid-input rules: [ADR 0036](./adr/0036-preserve-harbor-alpha-for-osc-default-colors.md). Successful reload advances the reset baseline while preserving explicit OSC RGB overrides; alpha follows accepted configuration, and failure changes neither baseline nor overrides ([ADR 0059](./adr/0059-atomic-manual-reload-and-terminal-only-fonts.md)).
- **Synonyms:** Dynamic default colors, OSC 10/11/12 colors
- **Relationships:**
  - depends on TerminalReply
  - references TOML User Settings
  - references Windows Acrylic Backdrop

### OSC Indexed Palette Policy
- **Definition:** Session-owned 256-entry OSC 4 set/query and OSC 104 reset palette, shared by primary/alternate and isolated across sessions; ANSI aliases resolve through matching slots. Whole malformed requests have no mutation/reply, valid operations execute in order, sets preserve alpha, and RIS/DECSTR/SGR reset preserve the palette. Indexed reset is separate from default/cursor/selection colors ([ADR 0053](./adr/0053-bounded-session-osc-palette-policy.md)). Reload uses the same latest-accepted baseline/explicit RGB override policy as OSC Default Color Policy, including OSC 104 reset ([ADR 0059](./adr/0059-atomic-manual-reload-and-terminal-only-fonts.md)).
- **Synonyms:** Dynamic indexed colors, OSC 4/104 palette
- **Relationships:**
  - depends on TerminalReply
  - depends on Parser Retention Limits
  - references TOML User Settings

### OSC 133 Shell-Integration Metadata
- **Definition:** Per-tab bounded prompt/command metadata: A prompt start, B prompt end, C command executed, D command finished with optional integer exit code. Unknown/malformed input is safely ignored; empty/RIS clears it. No UI chrome or PTY injection; see [ADR 0037](./adr/0037-osc133-shell-integration-metadata.md).
- **Synonyms:** Shell integration markers, FinalTerm semantic markers, FTCS markers
- **Relationships:**
  - communicates with Application Business Host
  - depends on Parser Retention Limits

### Focus Reporting
- **Definition:** Session-owned `?1004` emits `CSI I` / `CSI O` only on real focus gain/loss, not enablement or repeated observations. Observation continues while disabled, survives buffer swaps, and resets with enablement on RIS. See [ADR 0037](./adr/0037-session-owned-edge-triggered-focus-reporting.md).
- **Synonyms:** focus tracking, DECSET focus reporting
- **Relationships:**
  - communicates with Runtime Host
  - references Alternate-Screen Mode Family

### IME Preedit Composition
- **Definition:** Transient focused-terminal overlay at the live cursor, never screen/scrollback/pending-wrap/PTY content. Nonempty preedit hides the ordinary cursor, wraps/clips within the viewport and returns review to live bottom. Commit/cancel clears it and restores authoritative cursor state; shell echo, not synthetic advancement, positions committed text. See [ADR 0039](./adr/0039-route-ime-preedit-as-transient-terminal-overlay.md).
- **Synonyms:** preedit, composition text
- **Relationships:**
  - belongs to Terminal Input Semantics
  - communicates with Winit Adapter
  - depends on Terminal Widget Bridge

### VT Mouse Reporting
- **Definition:** Independent tracking (`?1003 > ?1002 > ?1000`) and encoding (`?1016 > ?1006 > ?1015 > ?1005 > legacy`) flags: disable reveals lower priority, queries report each flag, and encoding alone enables no tracking. Legacy CSI M is not press-only ?9 (unsupported); coordinates above its 223 limit are suppressed. SGR pixels are 1-based content-relative physical coordinates preserving sub-cell precision; WheelPixel instead describes delta units. Tracked input outranks local selection/scrollback even without emitted bytes; RIS clears flags. The multi-encoding/horizontal-wheel contract is [ADR 0055](./adr/0055-multi-encoding-mouse-reporting.md); [ADR 0038](./adr/0038-prioritized-sgr-only-mouse-reporting.md) records the earlier SGR-only boundary, not the extension's acceptance.
- **Synonyms:** SGR Mouse Reporting, SGR mouse tracking, DECSET mouse reporting
- **Relationships:**
  - communicates with Runtime Host
  - implements Terminal Pointer Interaction Policy

### OSC 52 Host-Authorized Clipboard Write
- **Definition:** Typed terminal requests, never terminal clipboard I/O; host revalidates the originating live session and applies its existing clipboard effect. Default allow requires active-tab main-window foreground eligibility; inactive/background/minimized/stale sources cannot write. Configurable allow/deny/confirm; reads remain denied. Confirm is an independent per-request window whose focus continues only its already-admitted request, with bounded preview and cancellation on source closure, tab change or external application focus ([ADR 0049](./adr/0049-osc52-confirmation-window-and-foreground-policy.md)). Fixed decoded UTF-8 capacity is 4 MiB, no capacity setting; only OSC 52 retention increases and overflow rejects whole requests ([ADR 0048](./adr/0048-bounded-osc52-specific-clipboard-capacity.md)).
- **Synonyms:** OSC 52 clipboard policy
- **Relationships:**
  - belongs to Terminal Tab
  - communicates with Application Business Host
  - references RuntimeEffects
  - depends on Parser Retention Limits

### OSC 52 Write Subset
- **Definition:** System clipboard only (`c` or empty selection), standard base64 with valid optional padding, UTF-8 without NUL; preserve tabs/newlines. Empty contents clear under identical authorization. Fragmented BEL/ST framing is supported; malformed/incomplete/unsupported/over-limit input changes nothing, and reads are denied. See [ADR 0050](./adr/0050-osc52-write-subset-and-bounded-request-delivery.md).
- **Relationships:**
  - belongs to OSC 52 Host-Authorized Clipboard Write

### OSC 52 Request Delivery
- **Definition:** Allow retains only the latest unexecuted valid write per originating live session; confirm retains one exact admitted request and rejects extras, never replaces its previewed contents. Execution revalidates identity/eligibility; denial/failure uses content-free diagnostics, not extra popups, terminal text or PTY error replies. See [ADR 0050](./adr/0050-osc52-write-subset-and-bounded-request-delivery.md).
- **Relationships:**
  - belongs to OSC 52 Host-Authorized Clipboard Write
  - communicates with Application Business Host

### Modern SGR Decoration Policy
- **Definition:** Independent underline style/color; explicit underlines/overlines paint spaces, OSC 8 fallback remains non-space single underline. Conceal hides foreground/decorations, not source text, background, width or copy: presentation, never redaction/disposable capacity. SGR status reflects authoritative state; verified styled support is discoverable via Su without identity changes ([ADR 0051](./adr/0051-modern-sgr-decoration-and-blank-retention-policy.md)). Meaningful Blank/Reflow define full history/non-ConPTY retention and the scoped ConPTY live-tail exception ([ADR 0052](./adr/0052-conpty-live-primary-producer-geometry-and-styled-tail-clipping.md)). Implementation does not certify unexercised runtime/transport paths.
- **Relationships:**
  - references OSC 8 Hyperlink
  - references DECRQSS
  - references XTGETTCAP
